# GuDuu Nexus · OEM 智能运营中心

一个零依赖、可直接运行的 OEM 运营大屏原型。默认打开全球 OEM 节点视图，并可切换至 3D 星系。全球视图使用世界六边形地图；3D 视图使用 Canvas 绘制 OEM 节点、实时链路和新节点诞生动画。两侧展示 Token 消耗、模型分布、调用效率、实时动态及资源配额。

## 本地运行

```bash
npm start
```

打开 `http://127.0.0.1:4173`。

## 已实现交互

- 悬停 / 点击星球节点查看 OEM 数据
- 拖动旋转 3D 星系视角，松手后带轻量惯性
- 滚轮缩放、视角复位和键盘方向键控制
- 按活跃状态筛选节点
- 全球地图 / 3D 星系两种中心视图切换
- 六边形逐格出现、悬停反馈与点击详情
- 全球 OEM 标签随机轮播，并在六边形悬停时自动隐藏
- 点击“接入 OEM”模拟新节点诞生
- 节点详情抽屉
- 动效暂停与全屏按钮
- 实时时钟和调用速率更新

当前数据为前端演示数据，可在 `app.js` 的 `OEMS` 数据源或后续 API 层中替换为真实数据。

## 地图数据

全球地图使用 Natural Earth 110m 世界陆地边界，并通过 `world-atlas` 发布版本预处理后随项目本地加载。Natural Earth 数据为 Public Domain；`world-atlas` 的 ISC 许可见 `assets/world-atlas-LICENSE.txt`。

如需更换地图源或调整六边形密度，可重新生成本地边界格：

```bash
npm run generate:map
```
