把 GuDuu OS 部署到你的服务器

网页版暂不提供免授权本地版。每个节点都需要独立 OEM 授权，并绑定审批时填写的部署域名。

注册成为 OEM 登录并申请授权
01

准备服务器与域名

Ubuntu 22.04/24.04 或 Debian 12，建议至少 4 核、8 GB 内存；域名 A/AAAA 记录先解析到服务器。

02

申请节点授权

在 OEM 控制台填写部署域名、用途和可选公网 IP，完成付款或平台主管审批后领取 KEY。

03

运行安装器

通过 SSH 在服务器运行发行版安装器。安装器强制校验 KEY 和域名，并直接拉取 CI 冻结的 Docker 摘要，不在服务器编译源码。

04

浏览器完成激活

若网络或 IP 校验暂时失败，节点只开放首次管理员激活页；修正配置后重新验证，成功才开放其他账号登录和注册。

部署前检查

  • 一个授权对应一个审批域名和一个节点。
  • 80/443 端口可用，或明确选择已有反向代理模式。
  • 服务器能够访问 Nexus，以及平台自建镜像仓或 GHCR 至少一处。
  • 准备 SMTP 配置；不配置时普通用户邮箱注册不可用。

安装命令只在授权获批后提供。请勿从第三方网站下载镜像或脚本，也不要使用可移动的 latest 标签。
