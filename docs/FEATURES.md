# GuDuu OS — 已开发功能清单

> 截至 2026-07-11。按模块整理"已上线可用"的功能;开发细节见 DEVLOG.md,欠账见 TODO.md。
> 用途:产品介绍/对外材料/新人了解全貌的单一入口。功能有增减时**顺手更新本文件**。

## 1. 账号与安全

- 注册:邮箱 6 位验证码注册(自建 SMTP 发码,Lark 邮箱);Cloudflare Turnstile 人机验证(可开关)
- 登录:账号/邮箱两种方式,统一走后端收口(限频/审计);密码强度校验(NIST 思路+弱密码表)
- 找回密码:邮箱验证码重置
- 风控:按邮箱+按 IP 双层限频;异地登录邮箱验证码 step-up;登录审计表(AuthEvent)
- 停用账号:登录提示"该账号已停用";运行中被停用 → 全局「登录已失效」提醒并回登录页;
  派单名册/频道邀请/私信自动过滤停用账号并给明确提示
- 多账号:本机缓存多账号一键切换
- 注册页「帮助/隐私政策」站内弹层,内容后台可编辑

## 2. IM 基础(基于 Synapse/Matrix,协议层零改动)

- 工作区(Space):创建/改名/图标上传/公开分享邀请链接/成员与角色管理(群主/管理员/成员)
- 频道:创建(工作区内查重防重名)/改名改简介(名称50字/简介200字上限)/公开与私密/归档灰显/
  收藏置顶分组/悬浮显示全名/退出;链接加入的成员也能把频道「归入」工作区(bot 代写挂接)
- 频道管理面板:人员(真实成员/邀请/移出/管理员徽章,AI 标「副频道主」)/技能/知识库(含文件上传)/
  数据权限/规则/模型/记忆审计——群级 AI 隔离配置,写进房间 state 多端同步
- 私信:发起(校验对方存在)/接受即入/未读数/新私信通知/对方停用或退出时"送不达"提醒;
  私信头部不显示频道专属控件(设置/成员/关于)
- 消息:Markdown 渲染/回复/编辑/表情回应/@提及/日期分隔/新消息跟随滚动
- 附件:图片缩略图+原图/视频音频内嵌播放/PDF与文本在线预览/其它下载卡片——全部走已认证媒体
  (Office 在线预览已评估暂缓,见 TODO E 区)
- 邀请:自动接受本服邀请;防外域垃圾邀请
- 在线状态:在线/忙碌/离开/隐身四态,指示灯变色,account data 持久跨端

## 3. 中枢 AI(主 AI 控制层)

- 多模型可插拔:echo/Claude/OpenAI/DeepSeek(方舟)/Gemini,无 key 自动降级;后台热切换
- 双引擎:legacy 直连 + Claude Agent SDK 引擎(env 开关,失败自动回退+控制室告警);
  群级模型联动——群绑定的智能体模型对两个引擎都生效
- 工具集(30+):建群/邀人(带权限自动提权与真实原因回报)/发消息(防私聊误发+回报真实频道名)/
  查成员/调聊天记录/跨频道清单(管理员可见全部)/知识库检索/联网搜索/人事与销售数据查询/
  跑工作流/建任务/改任务(状态/进度/结果/截止日期)/组专班/归档专班/征询选择(可点选项卡)等
- 双层作用域:频道分身只管本频道;右侧「私人会话」全局统筹(多会话,Recents 列表)
- 执行过程可见:工具调用滚动展示(中文动作名),Claude Code 式体验
- 记忆:短期对话历史+频道长期记忆摘要;记忆审计面板
- 交互准则内置基线+平台规则(控制室 RULE)+群人设+用户个人偏好(About me)逐层注入
- 会话失效/异常兜底:任何注入源失败只降级不断答

## 4. 智能体与技能

- 预置智能体 130 个:8 原生班底 + 122 引入(agency-agents 全库评估 242 条,中文化+中文备注,
  清单与否决理由永久留档 docs/agency-agents-import.md);后台「智能体」页分组展示,
  同 slug 覆盖即可改/停用
- 预置技能 13 个:结构化方法论(【何时启用】【铁律】【流程】【硬禁】),绑定智能体按需激活,
  绝不全局注入(token 预算铁律)
- Agent vs Skill 判断规则已沉淀:有身份能接活→Agent;可复用套路→Skill 绑 Agent
- **用户自建(我的AI工坊)**:每人可建 50 个智能体+50 个技能,归属本人账号、计入存储空间;
  自建智能体进本人派单名册(标「我的·」)、任意频道点名即应答;自建技能随人生效,
  与聊天命令「技能」同一份数据
- 资源级权限:技能/智能体带 access(所有人/付费/创作者/仅管理员/指定入驻模板),服务端强制
- 群绑定:频道可绑定智能体(人设+模型+技能整套生效);专班多 AI 协作(@名路由)

## 5. 知识库(RAG)

- 三级作用域:个人库(跟人走)/频道库(全频道共享,面板可上传文本文件)/平台共享库(后台维护)
- 入库方式:UI 上传/聊天命令/文档页自动同步/入驻模板预置灌库
- 检索:AI 回答自动带 RAG 片段;检索工具化(search_knowledge);组专班可把知识库"调进频道"
- 配额:文档篇数按会员等级限(free 5/paid 200/creator 不限);字节计入存储空间

## 6. 任务编排(模块 3.5 全档)

- 能力名册:真人(admin 全局+个人协作人,个人覆盖平台,停用/外域自动过滤)+智能体+技能+知识库
- 一键建专班:建频道(撞名自动加"专班"后缀)+拉人+绑 AI+任务 RULE+装技能+派单,一个动作完成;
  建成的频道自动挂进当前工作区
- 任务看板:待办/进行中/已完成三列;按工作区归属过滤;派给我的任务永远可见;
  截止日期+到期/逾期定时提醒;操作失败给真实报错
- 派单闭环:类型化执行者(真人/AI/工作流)/群内@通知被指派人/审核回填/归档收尾清记忆
- 我的协作人:给联系人补"擅长什么",主 AI 按能力派单;与后台「人员能力」个人覆盖平台语义

## 7. 工作流(模块 3)

- 不自建引擎,对接外部平台:通用 webhook/Dify/Coze/ComfyUI 连接器
- 后台可视化编排连接器(增删改查,凭据只填名、密钥只进服务端 env)
- 聊天命令「工作流 列表/跑」+ 主 AI 工具 run_workflow;异步回调协议;运行记录入库
- 安全:SSRF 防护/鉴权/防重放/限频(单实例"够用即止"口径)

## 8. 会员与变现(模块 4 · 地基+门控已通,真实支付待接)

- 会员等级:免费/付费/创作者(控制室管理,管理员不受门控);到期自动降级;DM 问 bot「会员」查等级
- 功能门控:能力→最低等级,后台逐项配,服务端强制(含工具层,防自然语言绕过)
- 用量配额:AI 对话条数/知识库篇数/专班数/工作流次数/**存储空间(MB)**——按等级配,后台可改;
  「我的额度」页实时展示进度条
- 存储空间:附件媒体+个人知识库+自建智能体/技能字节,free 100M/paid 1G/creator 5G 默认;
  个人库与自建内容服务端硬管控,附件上传前端预检
- 套餐与订单:套餐定义(控制室)/下单/幂等开通/续费顺延;mock(manual)支付通道可跑通业务链
