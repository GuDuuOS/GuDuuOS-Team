## 类型与升号

| 类型 | SemVer | 口径 |
|---|---|---|
| `bugfix` | PATCH | 纠正已有功能的错误，不新增用户能力 |
| `maintenance` | PATCH | 纯维护/性能/文案/基建调整，不新增用户能力 |
| `feature` | MINOR | 任何用户可感知的新页面、新流程、新接口或新行为 |
| `breaking` | MAJOR | 破坏兼容、强制迁移或负责人指定的产品代际 |
