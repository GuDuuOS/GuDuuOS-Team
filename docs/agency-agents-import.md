## Agent vs Skill 判断规则(负责人认可,以后新增内容照此)

- **有名有姓、能独立接活交付的角色 → Agent**(进智能体库,可被派单/@/绑群)
- **可复用的套路/清单/格式、要给多个角色叠加 → Skill**(进技能库,绑相关 Agent 随激活,**绝不全局注入**)
- 判断句:"这活交给谁?"的答案是 Agent;"按什么套路做?"的答案是 Skill。拿不准先 Agent。
- 已按此转换(2026-07-11):会议纪要专家→技能 meeting-notes(绑 项目推进管家/幕僚长/运营流程优化师)、
  高管摘要→executive-summary(绑 数据分析/商业战略/幕僚长)、搜索词分析→search-query-analysis
  (绑 PPC策略/投放审计)、轮播图策划→carousel-6slides(绑 小红书/Ins/TikTok/社媒运营*)、
  多平台分发策划→并入既有 platform-repurpose 技能(补知乎/B站适配,绑 内容创作策略师)。
