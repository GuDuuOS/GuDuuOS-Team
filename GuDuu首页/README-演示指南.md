# 海洋渔业生态 · 智能分身协作办公 Demo（蓝湾渔业）

基于 GuDuu 多智能体分身协作机制，覆盖 **捕捞、养殖、加工、销售** 四大核心业态，
搭配 **仓储物流、质检、总控管理、运维预警** 辅助分身的全链路协同演示。

## 启动

```bash
cd gudu-workbench
npm install        # 首次
npm run dev        # 默认 http://localhost:5175（PORT=xxxx 可改端口）
```

校验基线：`npm run type-check` 与 `npm run build` 必须通过。

## 开场：从零搭建向导（推荐作为演示第一幕，约 3 分钟）

刷新页面即进入**基础界面**：左侧只有「总控」一个工作区，频道和私信全空，GuDuu 总控分身弹窗出现（背景虚化但侧边栏可见）。通过 **7 步对话**现场"长"出整个系统，叙事线：**组织 → 人（权限）→ AI 分身 → 数据（眼）→ 技能（手）→ 协同空间（群权限）→ 启动**。

1. **行业识别**：「你的企业主营什么业务？」→ 海洋渔业全产业链 → **左侧工作区逐个长出**；
2. **邀请成员 + 角色权限**：三种邀请方式可选（**二维码/企业码、短信批量、邮箱批量**）→ 弹出邀请卡（伪二维码 + 企业码 LWYY-2026）→ 8 位成员加入动画 → **人类成员先进私信栏** → 角色权限逐条打勾（林经理=终审/审批/调价权，赵船长=出海确认权…）；
3. **智能创建分身**（演示亮点）：AI 问「想让 AI 替你做什么？大白话描述」→ 演示者随意输入（如"帮我管好出海捕捞和塘里养殖，订单卖货要盯紧，质量检测不能出问题"）→ AI 语义解析后给出**分身配置方案卡**：提到的职能标绿色「按你的描述」，没提到的标灰色「模板补齐」（总控、仓储这类必备角色 AI 自动补上）→ 分身逐个上线，强调"分身无终审权"；
4. **接入数据源**（给分身眼睛）：6 类数据源逐项打勾接通；
5. **技能装配**（给分身手）：从技能市场安装 /dispatch /trace /market /qc /report；
6. **频道 + 群权限 + 规则**：频道逐个长出；同步设定 公开/私密、**数据隔离（AI 记忆仅本群、ERP 对分身禁用）**、自动化规则——「每个群的 AI 都关进数据笼子」；
7. **导入启动**：「进入工作台 →」弹窗关闭，即完整 demo，演示心跳从此刻开始。

每步都可以用快捷按钮（演示稳）或自由输入（第 3 步用自由输入效果最好）。右上角「跳过搭建，直接进入」一键复原。

## 演示动线（8–12 分钟）

左侧工作区栏：**总控 / 捕捞 / 养殖 / 加工 / 销售** 五个工作区，各有独立驾驶舱与待办。

1. **全链路驾驶舱**（总控 → 全链路驾驶舱）
   今日订单 4000 斤、可调配货源 4500 斤、损耗率 12‰、AI 协同 86 次；
   业务环节状态网格 + 实时产销曲线 + 货源结构环图。

2. **核心剧本：#总控-订单全链路**（6 步闭环，对应方案步骤 1–6）
   - ① 周专员录入加急订单 4000 斤 → 销售分身解析（ORDER 卡片），A2A 推送总控/加工/仓储；
   - ② 加工分身产能核查 → 总控查库存缺口 2000 斤 → 养殖 1500 斤 / 捕捞 1000 斤应询 →
     多方协商「冷库优先→养殖补量→捕捞收尾」+ 货源分配图表 → **林经理人工批准**（关键操作终审）；
   - ③ 出塘/转运批次上报 → 质检分身抽检合格（QC PASS 卡片）；
   - ④ 加工分身双线排产，进度图实时同步，损耗率 1.2%；
   - ⑤ 仓储物流分身冷链匹配、路线规划（物流卡片）→ 销售分身同步客户；
   - ⑥ 总控分身订单复盘卡片（货源构成 / 时长 / 损耗 / 时效 / 毛利），推送负责人。

3. **拓展场景 A：#预警-风险联动**
   强对流预警 → 捕捞停航 → 销售调整接单 + 通知 12 家渠道 → 总控统筹养殖占比 70% → 负责人确认。

4. **拓展场景 B：#协商-货源冲突**
   双加急订单抢货 → 分身按合作等级/利润/违约成本博弈 → 超权限上报 → 林经理裁定 + 运费减免。

5. **分身私信视图**
   - 运维预警分身：冷链车厢温越限曲线、码头 CCTV 异常识别、台风预警；
   - 销售分身：大黄鱼批发价 7 日趋势（实际/AI 预测/历史平均）、渠道配比建议；
   - 质检分身：批次质检与溯源报告（文档预览，三批次构成 + 检测项 + 上链溯源）。

6. **右侧栏小蓝 AI（总控）— 6 个可操作流程**
   点击右上角 GuDuu logo 打开面板，输入框上方有 6 个快捷动作，全部可实操：

   | 流程 | 触发示例 | AI 执行效果 |
   |------|---------|------------|
   | ① 建群并拉人 | “为台风应急建一个专班群” | 按关键词推荐人选（捕捞/养殖/预警分身+赵船长），勾选确认后真实建群，侧边栏出现新频道 |
   | ② 查任务状态 | “汇总各业务群的任务状态” | 汇总 5 个工作区待办/进行/逾期成表 |
   | ③ 货源调度 | “帮我调配 3000 斤大黄鱼，明早发货” | 思考链：核库存→征询分身→出匹配方案卡；点「锁定货源」→ 向 #总控-订单全链路 发调度指令、频道红点 +1 |
   | ④ 停航应急 | “明天有强对流大风，启动停航应急联动” | 联动卡：捕捞停航/销售调整/养殖补供 3 项完成 + 报备单待人工终审；点「推送给林经理」→ #预警-风险联动 留痕、红点 +1 |
   | ⑤ 批次溯源 | “查一下批次 #YZ-0612-7 的溯源” | 输出 6 节点溯源档案卡；点「生成溯源码」→ #数据-溯源同步 留痕；可一键跳转频道 |
   | ⑥ 产销日报 | “生成今天的产销日报” | 汇聚 8 分身数据出日报卡；「推送负责人并归档」+ 跳转驾驶舱 |

   关键讲点：AI 执行的每一步都会**留痕到对应频道**（消息 + 未读红点），且关键操作（停航终审）保留人工确认权。

## 互动彩蛋（让系统"活着"的机制）

0. **驾驶舱 LIVE 曲线真滚动**：带 LIVE 角标的曲线每 2.5 秒轻微随机游走（基线/目标虚线不动）；**待办事宜**点状态圈可在 待办→进行中→已完成 间循环，顶部汇总实时联动；**CCTV 监控帧**时间码每秒走表 + REC 红点闪烁。
   注意：浏览器对后台标签页会暂停定时器——演示时保持窗口在前台即可。

0.5 **剧本一键重播**：每个有剧本的频道右上角有「▶ 重播演示」按钮——点击后清空消息、按 1.8 秒/条的节奏逐条上屏（带进度 n/20），适合配合讲解订单全链路；中途切频道会自动把剩余消息补全，剧本不丢。


1. **频道对话即时应答**：任何频道的输入框都能真发消息——你的消息上屏后，该频道对应的分身会显示"正在输入…"，约 1 秒后给出智能应答。支持关键词（库存 / 订单 / 海况 / 行情 / 进度 / 溯源 / 损耗 / 审批…）、`@质检分身` 等提及改写应答者、`/` 调出命令面板。演示时可现场让观众点题提问。
2. **演示心跳**：页面打开后约 25s / 60s / 100s / 145s / 190s / 240s / 300s，各分身会陆续产生真实动态（海况播报、排产确认、新订单、溯源上链、水质巡航、发运就绪、船队状态）——右上角弹通知（10 秒、可点击跳转频道），对应频道消息上屏 + 左侧红点 +1。讲解过程中系统会"自己动"。
3. **按钮留痕**：所有执行类按钮（含小蓝 AI 的操作）都会向相关频道追加"刚刚"的执行回执。
